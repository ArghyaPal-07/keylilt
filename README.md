# Keylilt
A quiet typing platform. React 19, Vite 6, Tailwind 4, React Router, and the existing Appwrite integration.

## Run
Use Node.js 22 or a compatible Vite 6 runtime.
```sh
npm ci
npm run dev
npm run build
npm run preview
npm test
npm run lint
```
The dev server uses http://127.0.0.1:4175/ to avoid conflicts with services using port 5173. If that port is occupied, Vite prints the next available port in the terminal.
